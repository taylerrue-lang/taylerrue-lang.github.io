# Privacy Policy – Faceless Shorts Uploader

Last updated: October 18, 2026

Faceless Shorts Uploader is a personal, non-commercial tool operated by its
owner (contact: taylerrue@gmail.com) to upload videos to the owner's own
YouTube channel.

## Data accessed
The app requests only the YouTube Data API scope
https://www.googleapis.com/auth/youtube.upload, used solely to upload videos
generated by the tool to the owner's channel. It does not read, collect or
store any data about other YouTube users, viewers or third parties.

## Storage and security
The OAuth credentials are stored as encrypted secrets in a private GitHub
repository and are used only by the automated upload job. No personal data
is sold, shared or transferred to anyone.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions

## YouTube and Google policies
This app uses YouTube API Services. By using it you agree to the YouTube
Terms of Service (https://www.youtube.com/t/terms). See also the Google
Privacy Policy (https://policies.google.com/privacy).
